# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting:
the **Security** tab of this repository, then **Report a vulnerability**. Do not open a public
issue for a vulnerability.

Include what you found, the steps to reproduce it, and the version (`leobot version`). You get
an answer as soon as the report has been read; fixes ship on `main` and in the next release.

## Supported versions

Only the latest release and `main` get security fixes.
