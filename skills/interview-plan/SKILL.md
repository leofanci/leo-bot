# Interview Plan

## Read first
- The role scope (outcomes, must-have skills). Missing: suggest `/role-scope` first.
- `projects/<project-slug>/strategy/intake.md` for context.
- A hiring list in the workspace, if any (`get-list`).

## Method
1. **Stages:** a short screen call, a work sample, a deep interview, a reference
   check. Fewer for a freelancer. Say the time each takes for both sides.
2. **Scorecard:** each must-have skill and each outcome, scored 1 to 4 with what a
   4 and a 1 look like. Filled in right after each interview, before discussing.
3. **Questions:** the same set for every candidate. Ask about past work ("Tell me
   about a time you..."), then follow up for detail (what they did, the result).
4. **Work sample:** a small, real-looking task, paid if it takes more than 2 hours,
   with the criteria shared upfront.
5. **Fairness:** no questions about age, family, health, religion, origin or other
   protected traits. Same time and the same questions for every candidate.
6. **Reference questions:** 3 to 5, on the outcomes that matter most.
7. **Candidate experience:** tell each candidate the steps and dates; answer every one.

## Options
Two or three process shapes: fast (screen plus paid trial project), standard (screen,
sample, interview), or thorough for a key hire. Trade-off: speed against confidence.

## Recommendation
The process to use, the scorecard, and the question set.

## Before you reply
- Every question links to a scorecard line.
- No question touches a protected trait.
- Messages to candidates are drafts that wait for the owner.
